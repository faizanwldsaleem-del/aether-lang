# Security Policy

The **Aether Programming Language** (`v7.5-CyberSec Master Edition`) contains built-in offensive security, penetration testing, and network auditing primitives (such as `hack_scan`, `packet_sniff`, and `exploit_dispatch`). We take the security of our runtime and ecosystem extremely seriously.

---

## 🛡️ Supported Versions

Only the latest stable release of Aether receives security updates and vulnerability patches.

| Version | Supported |
| :--- | :--- |
| v7.5 (CyberSec Master) | ✅ Active |
| < v7.0 | ❌ Discontinued |

---

## 🐞 Reporting a Vulnerability

If you discover a security vulnerability within the Aether compiler (`aetherc`), virtual machine (`avm`), or its embedded cybersecurity suites, please report it responsibly:

* **Contact Email:** Send details directly to the lead maintainer at `faizanwldsaleem-del@github.com` or open a private advisory on GitHub.
* **Information to Include:**
  * Type of vulnerability (e.g., buffer overflow in memory shields, enclave bypass, etc.).
  * Steps or a minimal `.ae` code snippet to reproduce the issue.
  * Potential impact assessment.

We pledge to review all reports within 48 hours and coordinate public disclosure patches securely.
